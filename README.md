## 这是什么
# 一部**网页端互动视觉小说**（视觉小说 = 以文字、立绘、背景、音乐推进的阅读式游戏）。
# 故事讲的是一只刚刚破壳的小勺嘴鹬，在出生后的第一个秋天，凭本能独自完成人生第一次南迁：
# 一路上它认识了蛎鹬、黑脸琵鹭、小青脚鹬、黑嘴鸥，在江苏盐城东台的**条子泥**滩涂停下来补给，看见了人们为候鸟做的事——巡护与监测、限制游客进入、720 亩高潮位栖息地、治理互花米草；也从年长的大滨鹬口中，听说了别处滩涂因为围垦、污染与外来植物而消失的故事。
